# Practice Set 6 – Flexbox

### Question 1
Create a navbar with 4 options in the form of anchor tags inside list items. Use Flexbox to place them all spaced equally in a single line.

### Question 2
Use Flexbox to center one div inside another div.

### Question 3
Which has higher priority – `align-items` or `align-self`?

**Answer:** `align-self` has higher priority because it overrides the `align-items` property for an individual flex item.
