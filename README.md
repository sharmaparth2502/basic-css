# Basic CSS

This repository contains my CSS examples and practice files covering basic styling concepts, selectors, layouts, responsive design, transitions, transforms, and animations.

## Topics Covered

The following CSS concepts are covered in this repository:

- Inline CSS
- Internal CSS
- External CSS
- CSS Selectors
  - Universal Selector
  - Element Selector
  - ID Selector
  - Class Selector
- Colors and Background Colors
- Text Alignment
- Text Decoration
- Font Weight
- Font Family
- Borders and Border Radius
- Width and Height
- Margin and Padding
- Display Property
  - Inline-block
  - None
- Visibility Property
- RGBA Colors and Transparency
- CSS Units
  - Pixels (px)
  - Percentage (%)
  - em and rem
  - Viewport Units (vh and vw)
- CSS Position Property
  - Static
  - Relative
  - Absolute
  - Fixed
  - Sticky
- CSS Flexbox
  - Display Flex
  - Flex Direction
  - Justify Content
  - Align Items
  - Gap
- CSS Grid
  - Display Grid
  - Grid Template Columns
  - Gap
- CSS Media Queries
  - Max Width
  - Responsive Layouts
- CSS Transitions
  - Transition Property
  - Transition Duration
  - Transition Timing Function
  - Transition Delay
- CSS Transform
  - Rotate
  - Scale
  - Translate
  - Skew
- CSS Animations
  - Animation Name
  - Animation Duration
  - Animation Iteration Count
  - Keyframes

## CSS Practice Questions

This section contains practice questions and their HTML/CSS solutions, organized into separate practice sets.

- **Practice Set 1:** Divs, headings, buttons, and CSS styling
- **Practice Set 2:** Text alignment, fonts, and nested divs
- **Practice Set 3:** Borders, border radius, and navbar styling
- **Practice Set 4:** Page layout, borders, colors, and opacity
- **Practice Set 5:** Background images, positioning, and z-index
- **Practice Set 6:** Flexbox navbar and centering elements
- **Practice Set 7:** Media queries and responsive background colors
- **Practice Set 8:** CSS loader and animations

Each practice set includes a Markdown file containing the questions and the corresponding HTML and CSS files.
